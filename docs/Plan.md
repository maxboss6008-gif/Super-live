# Plan — এখন পর্যন্ত কী হয়েছে, পরে কী বাকি

## ✅ হয়ে গেছে
- P1: auth (রেজিস্টার/লগইন/২FA/লকআউট/রিফ্রেশ), ওয়ালেট+লেজার, পেমেন্ট (প্লাগেবল গেটওয়ে),
  মেসেজ/কল বিলিং, KYC (ম্যানুয়াল), উইথড্রয়াল, মডারেশন (রিপোর্ট-ভিত্তিক), মালিকের নিয়ন্ত্রণ,
  লেভেল, ব্যানার, মাইগ্রেশন, রেট-লিমিট, ইউনিট+e2e টেস্ট
- P2: অডিও/ভিডিও রুম (Redis-ব্যাকড, মাল্টি-ইনস্ট্যান্স), লক, ব্ল্যাকআউট, চ্যাট রিলে, LiveKit
  টোকেন ইস্যু, মডারেশন/কিল-সুইচ হুক
- P3: লগইন, লেনদেন, উইথড্রয়াল, ফ্রড, সার্ভার-নিয়ন্ত্রণ ট্যাব
- P4: লগইন/২FA, ওয়ালেট (অফলাইন ক্যাশ), রুম তালিকা, রুম স্ক্রিন (চ্যাট + LiveKit কোড লেখা)
- CI: typecheck/lint/audit/e2e (আসল Postgres+Redis), EAS বিল্ড ওয়ার্কফ্লো

## ❌ পরবর্তী ধাপে বাকি (অগ্রাধিকার অনুযায়ী)
1. **মোবাইলে LiveKit ডিভাইসে টেস্ট করা** — কোড লেখা আছে, কখনো চালিয়ে দেখা হয়নি (docs/TRD.md)
2. **মোবাইলে গিফট, KYC জমা, উইথড্রয়াল অনুরোধ UI** — ব্যাকএন্ড এন্ডপয়েন্ট আছে, স্ক্রিন নেই
3. **অ্যাডমিনে KYC রিভিউ, সুপার-অ্যাডমিন টগল, ব্যানার/লেভেল ম্যানেজমেন্ট ট্যাব**
4. **আসল পেমেন্ট গেটওয়ে** (Al Rajhi/Moyasar/HyperPay, যেটাই চূড়ান্ত হয়) — এখন Stripe রেফারেন্স
5. **আসল PayoutProvider** (ব্যাংক ট্রান্সফার API) — উইথড্রয়াল অনুমোদনের পর এখন ম্যানুয়াল
6. **নিজের মেশিনে/CI-তে `npm audit`, ESLint সত্যিই একবার চালিয়ে ফলাফল দেখা**
7. **Play Store অ্যাসেট** (আইকন, স্ক্রিনশট, প্রাইভেসি পলিসি URL) — docs/legal/play-store-checklist.md
8. **ডিজাইন পাস** — এখনকার UI ইচ্ছাকৃতভাবে ন্যূনতম (docs/UI_Spec.md)

## স্থগিত/প্রত্যাখ্যাত (ইচ্ছাকৃতভাবে বানানো হয়নি)
