# AppFlow — মূল ইউজার ফ্লো

## ১. রেজিস্ট্রেশন ও লগইন
```
রেজিস্ট্রেশন → TOTP সিক্রেট পাওয়া (QR বানিয়ে অথেনটিকেটরে স্ক্যান) → লগইন
  → পরিচিত ডিভাইস? → হ্যাঁ: সরাসরি accessToken+refreshToken
                    → না: ২FA চ্যালেঞ্জ (challengeId) → অথেনটিকেটরের কোড → টোকেন
৫ বার ভুল পাসওয়ার্ড → ৩০ মিনিট লক (পুনরায় ২৪ ঘণ্টার মধ্যে হলে ২৪ ঘণ্টা)
ফোন হারালে → অ্যাডমিন পরিচয় যাচাই করে ২FA রিসেট → পরের লগইনে ৪৮ ঘণ্টা উইথড্রয়াল বন্ধ
```

## ২. লাইভ রুমে ঢোকা ও আড্ডা
```
রুমের তালিকা (GET /rooms) → রুম বেছে নেওয়া
  → লক করা? → পাসওয়ার্ড চাওয়া → joinRoom (ভুল হলে প্রত্যাখ্যান)
  → না লক করা → সরাসরি জয়েন
জয়েন সফল → LiveKit টোকেন পাওয়া → অডিও/ভিডিও সংযোগ + টেক্সট চ্যাট
চ্যাট মেসেজ পাঠানো → দৈনিক ফ্রি কোটার মধ্যে ফ্রি, তারপর কয়েন কাটে → কয়েন না থাকলে পাঠানো যাবে না
হোস্ট চাইলে রুম লক/আনলক করতে পারেন
```

## ৩. গিফট পাঠানো (ব্যাকএন্ড লজিক আছে, মোবাইল UI এখনো নেই)
```
ইউজার → গিফট (কয়েন + প্রাপক আইডি + idempotency key)
  → প্রেরকের কয়েন কাটা (আনলিমিটেড হলে কাটে না)
  → ৮০% প্রাপকের আয়ে, ২০% প্ল্যাটফর্ম ফি
```

## ৪. কলিং
```
ইউজার → হোস্টকে কল (ব্যস্ত/অন্য কলে থাকলে প্রত্যাখ্যান)
  → প্রথম মিনিট অগ্রিম কাটা → প্রতি মিনিটে আবার কাটা (tick)
  → কয়েন শেষ হলে কল স্বয়ংক্রিয়ভাবে শেষ
```

## ৫. উইথড্রয়াল
```
ক্রিয়েটর → KYC অনুমোদিত? না হলে → প্রত্যাখ্যান
  → হ্যাঁ → উইথড্রয়াল অনুরোধ (কয়েন হোল্ড হয়ে যায়, ডাবল-স্পেন্ড আটকাতে)
  → অ্যাডমিন অনুমোদন/বাতিল (বাতিলে হোল্ড ফেরত)
  → অনুমোদনের পর আসল ব্যাংক ট্রান্সফার এখনো ম্যানুয়াল (PayoutProvider ইন্টিগ্রেশন বাকি)
```

## ৬. মডারেশন (রিপোর্ট-ভিত্তিক, গোপন নয়)
```
যেকোনো ইউজার → রিপোর্ট দাখিল (মেসেজ/রুম/কল/ইউজার + কারণ)
  → অ্যাডমিন শুধু খোলা রিপোর্টের ভিত্তিতে প্রবেশ করতে পারেন (পরিচয় প্রকাশ্য, অডিট লগ)
  → নিষ্পত্তি (resolved/dismissed)
```

## ৭. মালিকের জরুরি নিয়ন্ত্রণ
```
মালিক → মাস্টার কিল সুইচ → পুরো অ্যাপ বন্ধ (সর্বোচ্চ ২৪ ঘণ্টা, এরপর স্বয়ংক্রিয় চালু)
  → অথবা শুধু কার্ড ডিজেবল (সার্ভার বিলিং বন্ধ)
```
