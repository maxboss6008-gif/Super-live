# Super Live International — Product Requirements Document (PRD)

## ১. পণ্যের সংক্ষিপ্ত পরিচিতি
একটা লাইভ-স্ট্রিমিং সামাজিক অ্যাপ, যেখানে ইউজাররা অডিও/ভিডিও রুমে ঢুকে আড্ডা দেন, হোস্টদের
ভার্চুয়াল কয়েন দিয়ে গিফট পাঠান, সরাসরি কল করেন; ক্রিয়েটর ও এজেন্টরা সেই গিফট থেকে আয় করে
উইথড্র করতে পারেন; আর মালিক/অ্যাডমিন পুরো প্ল্যাটফর্মের আর্থিক ও নিরাপত্তা নিয়ন্ত্রণ রাখেন।

## ২. ইউজার রোল
| রোল | মূল কাজ |
|---|---|
| user | রুমে ঢোকা, গিফট পাঠানো, কল করা, চ্যাট |
| creator | হোস্টিং, গিফট/কল থেকে আয়, উইথড্রয়াল |
| agent | ক্রিয়েটরদের ম্যানেজ করে কমিশন পাওয়া (ব্রোঞ্জ/সিলভার/গোল্ড ধাপ) |
| admin | রিপোর্ট পর্যালোচনা, KYC/উইথড্রয়াল অনুমোদন |
| super_admin | অ্যাডমিন + এনটাইটেলমেন্ট/লেভেল/ব্যানার নিয়ন্ত্রণ |
| owner | মাস্টার কিল সুইচ, কার্ড নিয়ন্ত্রণ, সিস্টেম সেটিংস |

## ৩. মূল ফিচার (বর্তমানে কোড হয়েছে)
- ইমেইল+পাসওয়ার্ড রেজিস্ট্রেশন, বাধ্যতামূলক TOTP ২FA, নতুন-ডিভাইস চ্যালেঞ্জ, ৫-বার-ভুলে লকআউট
- ওয়ালেট: কয়েন কেনা (পেমেন্ট গেটওয়ে প্লাগেবল), গিফট (২০% প্ল্যাটফর্ম ফি), ১ বছরের স্টেটমেন্ট
- লিমিটেড/আনলিমিটেড কয়েন (সুপার অ্যাডমিন টগল করেন)
- কয়েন-চার্জড মেসেজিং (দৈনিক ফ্রি কোটার পর), প্রতি-মিনিট কয়েন কাটা কলিং
- অডিও/ভিডিও লাইভ রুম (৩০ জন পর্যন্ত), লক/আনলক, অ্যান্টি-রেকর্ডিং ব্ল্যাকআউট ইঙ্গিত
- KYC (ম্যানুয়াল রিভিউ) ও উইথড্রয়াল অনুরোধ/অনুমোদন
- রিপোর্ট-ভিত্তিক, অডিট-লগড মডারেশন (গোপন নজরদারি ইচ্ছাকৃতভাবে বাদ — docs/SECURITY_AUDIT.md দেখুন)
- মালিকের ড্যাশবোর্ড: মাস্টার কিল সুইচ, কার্ড এনাবল/ডিজেবল, রানটাইম সেটিংস
- লেভেল সিস্টেম (গিফট-ভিত্তিক স্বয়ংক্রিয় বা আইডি-ভিত্তিক ওভাররাইড), ব্যানার

## ৪. এই সংস্করণে যা নেই (Plan.md-এ বিস্তারিত)
- মোবাইলে গিফট পাঠানোর UI, KYC ডকুমেন্ট জমা দেওয়ার UI, সুপার-অ্যাডমিন টগল UI
- আসল পেমেন্ট গেটওয়ে (Al Rajhi/Moyasar ইত্যাদি) — এখন Stripe রেফারেন্স + Mock
- LiveKit অডিও/ভিডিও ডিভাইসে পরীক্ষিত নয়

## ৫. সাফল্যের মাপকাঠি (প্রস্তাবিত, চূড়ান্ত না)
- দৈনিক সক্রিয় রুম সংখ্যা, গড় রুম-সময়, গিফট রূপান্তর হার, উইথড্রয়াল প্রসেসিং সময় (স্পেক: ৩-৫ কর্মদিবস)
