# UI_Spec — স্ক্রিন ইনভেন্টরি

এই ডকুমেন্ট যা **সত্যিই কোডে আছে** তার তালিকা — কোনো ডিজাইন মকআপ না। প্রতিটা স্ক্রিনের
ফাইল পাথ দেওয়া আছে, যাতে কেউ গিয়ে সরাসরি দেখতে পারেন।

## কম্পোনেন্ট-লেভেল নোট
- মোবাইলের সব স্ক্রিন একই রঙের প্যালেট ব্যবহার করে (`#e5254f` ব্র্যান্ড, `#ece8f6` ব্যাকগ্রাউন্ড) —
  কোনো ডিজাইন সিস্টেম ফাইল আলাদা করে নেই, সরাসরি StyleSheet-এ।
- অ্যাডমিন ড্যাশবোর্ডে কোনো CSS ফ্রেমওয়ার্ক নেই, ইনলাইন `<style>` ট্যাগে।
- এগুলো ইচ্ছাকৃতভাবে ন্যূনতম — একটা প্রোডাকশন-মানের ডিজাইন পাসের জন্য আলাদা কাজ লাগবে।
